# python-refresher-2026

A practical Python refresher for developers who know the syntax and want to build the engineering habits required to ship reliable, observable, reproducible software.

## Why this exists

Python tutorials teach the language. Professional work also requires reproducible environments, dependency locking, regression tests, static analysis, debugging, performance awareness, CI, and deliberate concurrency choices.

This repository documents that gap through small, runnable units. Each unit starts from a realistic failure, constraint, or boundary — not a syntax exercise.

## Who this is for

Developers and students who already know Python fundamentals and want to refresh for professional work.

It is not a beginner course.

## What this will cover

- Reproducible Python projects with `uv`
- Testing, type contracts, linting, and CI
- Python's execution model, data structures, iteration, functions, errors, and the data model
- Debugging, profiling, concurrency decisions, and the high-value standard library
- Modern Python changes from 3.8 through 3.14

## What this deliberately skips

Basic syntax, `for` and `while` tutorials, list-method walkthroughs, to-do apps, OOP through animal examples, notebooks, data-science exercises, machine-learning projects, and web frameworks.

Those resources already exist everywhere. This repository focuses on the reasoning and engineering practice that follows.

## Status

Foundation in progress. The first runnable unit is not published yet.
